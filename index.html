Get Started

One command. Ready to brew.

Install AnkChaiCSS via npm, then drop one script tag and every chai- utility class is live — no build step, no config.

01

Install via npm

Run this in your project terminal:

$ npm i ankchaicss
02

Add the script tag

Paste this at the bottom of your HTML, just before </body>:

<script src="node_modules/ankchaicss/src/script.js"></script>
03

Start using chai- classes

That's it — no config, no build. Just write:

<div class="chai-flex chai-p-4 chai-rounded-lg chai-bg-teal"> <p class="chai-text-xl chai-font-bold chai-text-white">Hello,Chai!</p> </div>
